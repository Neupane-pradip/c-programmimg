# C Programming Practice

A small C exercise in loops, conditions, divisibility, and formatted output.

## Program

[`luvut.c`](luvut.c) prints the integers from **1 through 100** that are not divisible by **2, 3, or 5**. Values are separated by spaces and the output ends with a newline.

## Build and run

Install a C compiler such as GCC, then run from the repository root:

```sh
gcc -std=c11 -Wall -Wextra -pedantic luvut.c -o luvut
./luvut
```

On Windows with GCC, build with `-o luvut.exe` and run `.\luvut.exe` in PowerShell.

No external libraries or input files are required.

## Scope

This repository contains one introductory exercise. It is a learning example rather than a larger application.
